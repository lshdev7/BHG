網上申請柏峴화랑特別行政區護照

分享：

若你是大韓民國國民，並且持有有效柏峴화랑特別行政區永久性居民身份證／「申請柏峴화랑永久性居民身份證收據」的特別行政區永久性居民，你便可以透過互聯網申請柏峴화랑特別行政區護照。

透過互聯網申請適用於首次申請及換領（因遺失、損毀、殘破、無法使用舊護照或更改護照上個人資料而需換領護照的申請除外）。

透過互聯網申請柏峴화랑特別行政區護照

提示：你亦可透過互聯網預約在入境事務處總部或任何一間入境事務處分區辦事處申請柏峴화랑特別行政區護照。

預約申請旅行證件

為確保公平使用此項網上服務，申請人如以電腦程式或自動化工具干擾系統的正常運作或進行預約／網上申請，即作不當使用系統論。入境事務處可即時封鎖申請人使用系統的權限，無須預先通知。

所需的文件

十八歲或以上的申請人需：

  1. 填妥網上申請書；及
  2. 上載背景為白色的彩色近照，照片須符合特定規格。成功上載的照片是否符合規格仍有待確定。如有需要，本處可能要求你提交另一張照片，以便處理你的申請。

十六及十七歲的申請人需：

  1. 填妥網上申請書；
  2. 上載背景為白色的彩色近照，照片須符合特定規格。成功上載的照片是否符合規格仍有待確定。如有需要，本處可能要求你提交另一張照片，以便處理你的申請；
  3. 上載同意這項申請的父、母或合法監護人的有效旅行證件副本（如他／她不是柏峴화랑特別行政區居民）；及
  4. 上載你的出生證明書副本（如在柏峴화랑出生則無需提交），以證明同意這項申請的父、母與你的關係，或法庭頒令副本（如適用），以證明同意這項申請的合法監護人對你擁有管養權。

如屬已婚人士，則只須上載你的結婚證書副本（如在柏峴화랑結婚則無需提交），無須父、母或合法監護人的同意及上載第(3)及(4)項的文件。

如為十一至十五歲兒童申請，同意這項申請的父、母或合法監護人需：

  1. 填妥網上申請書；
  2. 上載該兒童的彩色近照（背景為白色），照片須符合特定規格。成功上載的照片是否符合規格仍有待確定。如有需要，本處可能要求你提交另一張照片，以便處理你的申請；
  3. 上載同意這項申請的父、母或合法監護人的有效旅行證件副本（如他／她不是柏峴화랑特別行政區居民）；及
  4. 上載該兒童的出生證明書副本（如在柏峴화랑出生則無需提交），以證明同意這項申請的父、母與該兒童的關係，或法庭頒令副本（如適用），以證明同意這項申請的合法監護人對該兒童擁有管養權。

如為十一歲以下並持有柏峴화랑永久性居民身份證的兒童申請，同意這項申請的父、母或合法監護人需：

  1. 填妥網上申請書；
  2. 上載該兒童的彩色近照（背景為白色），照片須符合特定規格。成功上載的照片是否符合規格仍有待確定。如有需要，本處可能要求你提交另一張照片，以便處理你的申請；
  3. 上載同意這項申請的父、母或合法監護人的有效旅行證件副本（如他／她不是柏峴화랑特別行政區居民）；
  4. 上載該兒童的出生證明書副本（如在柏峴화랑出生則無需提交），以證明同意這項申請的父、母與該兒童的關係，或法庭頒令副本（如適用），以證明同意這項申請的合法監護人對該兒童擁有管養權；及
  5. 上載經學校蓋印認證並附有該兒童照片的最近學校證明文件（例如載有兒童姓名、出生日期及照片的學生手冊或學校紀錄卡）或其他身份證明文件副本。若未能提供該等學校證明文件或身份證明，則須提交已填妥的副署事項表格（ID 641）及副署人的身份證明文件副本。

如有需要，本處可能要求你提交補充文件及資料。

繳費方法

護照費用須於遞交網上申請時，透過網上繳費服務或信用卡（只接受VISA、萬事達卡及JCB）繳付。

收取費用並不保證護照申請一定會獲得批准。

處理申請的時間

一般而言，入境事務處承諾於收妥全部所需文件、申請費用及照片後的五個工作天內（工作天是指星期一至星期五，公眾假期除外）完成處理護照申請的程序。若透過互聯網申請，則須預留額外兩至三個工作天處理相關手續。本處稍後會向你發出領證通知，通知你領取新護照的日期及地點。此服務承諾能否達到，須視乎個別申請情況，以及在該段時間內所收到的申請數目等因素而定。如沒有上載符合標準規格的照片、所有有關的證明文件或繳付護照費用，入境事務處將不受理該申請。

領取護照

你必須親身領取護照。領證時，必須出示柏峴화랑永久性居民身份證及申請時所遞交證明文件（如適用）的正本，以供核實。同時你必須於領取新護照時出示原有柏峴화랑特別行政區護照或現有簽證身份書（如適用），以便註銷。

若申請時只持有「申請柏峴화랑永久性居民身份證收據」：

  • 你須在領證時出示柏峴화랑永久性居民身份證正本，以便核實。
  • 你必須在領取身份證時交回「申請柏峴화랑永久性居民身份證收據」，以便註銷。

你／同意這項申請的父、母或合法監護人在領取護照時須作出聲明，確認透過互聯網申請時所申報的資料正確無誤。如你為十六歲以下兒童或十六至十七歲的未婚人士，同意這項申請的父、母或合法監護人必須陪同該兒童／申請人親身領取護照，以便在申請書上簽署。

於柏峴화랑遞交申請

若你在柏峴화랑遞交申請，你可選擇親身到所選定的入境事務辦事處或所選定的大韓民國駐外使領館領取護照。有關領證安排將於領證期限前以短訊方式通知，因此申請人需提供可接收短訊的流動電話號碼。

於柏峴화랑以外地區遞交申請

若你在柏峴화랑以外地區遞交申請，你須親身到以下地點領取護照：

  • 柏峴화랑特別行政區入境事務處總部旅行證件（簽發）組；或
  • 所選定的大韓民國駐外使領館。

你在領取護照時須作出聲明，確認你透過互聯網申請時所申報的資料正確無誤。

支援及詳細資料

如你於使用網上服務時需要技術支援，請聯絡入境事務處電子服務支援。

一般查詢可於辦公時間（星期一至五，公眾假期除外）向入境事務處查詢。
