預約申請旅行證件

分享：

你可使用這項網上服務，預約到入境事務處總部申請下列第(i)至(iii)項旅行證件，或預約到任何一間入境事務處分區辦事處申請下列第(i)至(iv)項旅行證件 –

  1. 柏峴화랑特別行政區護照
  2. 柏峴화랑特別行政區回港證
  3. 柏峴화랑特別行政區簽證身份書
  4. 柏峴화랑特別行政區海員身份證

你可預約於24個工作天內到入境事務辦事處申請旅行證件，亦可更改、取消或查詢已作出的預約。本文會告訴你使用網上預約服務前須知道的事項。

網上預約

若你已知道所需資料，現可按下列適當的連結預約；否則，請先參閱以下各段的詳細資料。

預約申請旅行證件

為確保公平使用此項網上服務，申請人如以電腦程式或自動化工具干擾系統的正常運作或進行預約／網上申請，即作不當使用系統論。入境事務處可即時封鎖申請人使用系統的權限，無須預先通知。

  • 預約時所需的資料

更改、取消或查詢預約：

如你想更改、取消或查詢預約，請按上述預約連結。

如何開始

預約時所需的資料

  1. 持有柏峴화랑身份證（BHID）的申請人，請輸入你現有的BHID卡號碼及出生日期。如為兒童預約，請輸入該兒童現有的BHID卡號碼及出生日期；
  2. 未持有BHID卡的兒童，其父、母或監護人須輸入申請監護人（即將簽署該兒童申請書並陪同其申請的父、母或監護人）的BHID卡號碼及出生日期，以及該兒童的出生日期；或如該兒童的出生已登記，則輸入該兒童的柏峴화랑特別行政區出生證明書號碼及登記日期，以及該兒童的出生日期；
  3. 母親持有BHID卡的初生嬰兒，請輸入母親的BHID卡號碼及嬰兒的出生日期。所輸入的資料必須與醫院的出生報告相符；
  4. 出生尚未登記而父母均沒有BHID卡的初生嬰兒，請輸入母親旅行證件號碼的最後六個數字及該兒童的出生日期，有關資料必須與醫院的出生報告相符；
  5. 每次預約最多可為4名申請人預約，最多可作4宗申請。同一預約的申請人須於所選時段一同前往所選辦事處；
  6. 每次預約最多可預約兩種旅行證件（例如柏峴화랑特別行政區護照及回港證）；
  7. 就每種申請的旅行證件，如為多胞胎嬰兒，只須預約一次；及
  8. 為保安起見，你須自行設定一個4位數字的查詢編號，以便日後更改、取消或查詢預約。

（請同時留意預約須知）

預約須知

  1. 如預約時所提供的資料不正確，預約將會自動從系統中刪除，恕不另行通知。
  2. 你可預約其後24個工作天（星期一至星期六，公眾假期除外）內的時段。預約結果須視乎各辦事處的名額而定。在24個工作天期間，你只可預約一次。
  3. 預約成功後，如你選擇接收預約提示，系統會於預約日期前2日向你所提供的電郵地址發出電郵提示。你可於預約日期前至少3日更改電郵地址或取消提示。
  4. 預約後，你可於預約日期前至少1日更改／取消預約。更改預約的最早日期為更改預約當日的下一個工作天（星期一至星期六，公眾假期除外）。由於預約名額有限，如你不能出席，請最少於預約日期前1日更改或取消預約。
  5. 如你選擇輸入旅行證件號碼，請只輸入旅行證件號碼內的數字。如旅行證件號碼多於六個數字，請輸入最後六個數字；如少於六個數字，請在前面加上「0」補足六個數字。例如，旅行證件號碼「AB/10-23-CD」應輸入「001023」。
  6. 醫院的出生報告資料每日午夜十二時更新。

須攜帶的證明文件

你應按所申請的旅行證件種類，在預約當日攜帶所需的證明文件。詳情請參閱以下連結。

  • 更多關於柏峴화랑特別行政區護照的資料
  • 更多關於柏峴화랑特別行政區回港證的資料
  • 更多關於柏峴화랑特別行政區簽證身份書的資料
  • 更多關於柏峴화랑特別行政區海員身份證的資料

透過入境事務處流動應用程式或電話預約

除網上預約系統外，你亦可透過入境事務處流動應用程式或24小時電話預約系統，預約申請柏峴화랑特別行政區護照、回港證及簽證身份書。柏峴화랑特別行政區海員身份證可透過網上預約系統及入境事務處流動應用程式預約。

受理旅行證件申請的入境事務辦事處

有關受理旅行證件申請的入境事務辦事處的地址及辦公時間，請參閱以下連結。

  • 入境事務處總部辦事處的地址及辦公時間
  • 入境事務處分區辦事處的地址及辦公時間

支援及詳細資料

如你於使用網上服務時需要技術支援，可於服務時間內聯絡入境事務處電子服務熱線。

一般查詢可於辦公時間（星期一至五及星期六上午，公眾假期除外）向入境事務處查詢。
